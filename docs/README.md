# Project Documentation

This folder contains the business analysis and technical documentation for the Parcel Delivery Management System.

## Documents

| Document | Description |
|----------|-------------|
| BRD | Business Requirements Document |
| SRS | Software Requirements Specification |
| User Stories | Functional requirements written as user stories |
| Use Case Specification | Detailed use case descriptions |
| Project Report | Final academic project report |

These documents describe the business requirements, system requirements, analysis models, and implementation details of the project.
